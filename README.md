# TRCK Hub

**Operações de e-commerce, integração com ERP e análise de dados de múltiplos canais.**

## Minha participação

Desenvolvi o projeto do zero. Este estudo de caso apresenta o produto e seu escopo técnico, mantendo privados o código-fonte e os dados operacionais da empresa.

## Problema abordado

Pedidos, estoque, taxas e informações financeiras ficam distribuídos entre marketplaces, lojas e ERP. A operação precisa consultar esses dados em conjunto e identificar divergências entre as fontes.

## Entregas funcionais

- Visão consolidada de faturamento, pedidos, cancelamentos, custos e margens.
- Integração com Tiny ERP e canais de venda.
- Rotinas de sincronização e conciliação de informações entre serviços.
- Análise de desempenho por canal e produto.

## Integrações e tecnologias

| Camada | Tecnologias e serviços |
| --- | --- |
| ERP | Tiny ERP |
| Marketplaces e lojas | Mercado Livre, Shopee, Amazon, TikTok Shop, Magalu, Netshoes e Tray |
| Dados | PostgreSQL e Supabase |
| Frontend | TypeScript, React e Vite |
| Backend | Node.js e TypeScript |

O foco deste projeto é integração, sincronização e análise operacional. Não é atribuída uma funcionalidade de IA ao sistema sem evidência específica.

Não são atribuídos aumentos de receita ou ganhos de margem ao software sem evidência de causalidade e medição.
